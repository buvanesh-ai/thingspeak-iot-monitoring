 ThingSpeak IoT Monitoring Projects

A collection of IoT sensor monitoring projects using **ThingSpeak** for cloud-based data storage, visualization, and monitoring.

🚀 Projects

1. ADXL345 Monitoring

Collects motion and acceleration data from the **ADXL345 accelerometer** and sends the data to ThingSpeak for cloud monitoring.

2. BMP280 Monitoring

Uses the **BMP280 sensor** to collect environmental data such as temperature and pressure and upload it to ThingSpeak.

3. DHT Sensor Monitoring

Collects **temperature and humidity** data using a DHT sensor and sends the readings to ThingSpeak for visualization.

4. Gas Sensor Monitoring

Monitors gas sensor readings and uploads the collected data to ThingSpeak for remote observation.

5. Ultrasonic Monitoring

Uses an **ultrasonic sensor** to measure distance and sends the readings to ThingSpeak for cloud-based monitoring.

⚙️ How It Works

The connected sensor collects real-time data through the microcontroller. The microcontroller connects to the internet using Wi-Fi and sends the sensor readings to **ThingSpeak**, where the data is stored and displayed through cloud-based charts and visualizations.

📊 Cloud Monitoring

ThingSpeak was used to:

* Store sensor data in the cloud
* Visualize sensor readings
* Monitor changing values over time
* Create separate data channels for different sensors
